Status Logic Explanation

  • Available (1): Can add or remove. When adding, collection time is set to current timestamp. When removing, the bag closest to expiry is marked as deleted (not shown in frontend).
  • Expired (2): Can add or remove. Expired bags are shown in inventory but cannot be used.
  • Used (3): Can only add (irreversible). When adding used bags, available count decreases accordingly.
  • Delivered (4): Can add or remove. When adding delivered bags, available count decreases. When removing delivered bags, available count increases.
  • Deleted (0): Not shown in frontend. This is a system status only.
